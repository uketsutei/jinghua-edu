# 菁华教育 · 网课学习平台

**线上地址：https://uketsutei.github.io/jinghua-edu/**

> 这是一个**全栈项目**：静态网站 + Node/SQLite 后端。
> 只想要静态演示站？打开 `index.html` 即可。
> 想要「改完所有人都能看到」+ 真实用户/订单/进度数据？看下面的「后端部分」。

一个可以直接双击打开使用的在线课程平台网站，包含首页、课程中心、课程详情（带播放器）、
我的学习、名师团队、登录注册六个页面。无需安装任何软件，也不需要联网。

---

## 一、后端部分（全栈怎么跑起来）

### 1. 本机启动（30 秒）

双击文件夹里的 **`启动服务器.bat`**，或者在命令行执行：

```
node server/server.js
```

然后浏览器打开 http://localhost:3000/ —— 网站和后端接口一起跑起来了。

**零依赖**：只用 Node 自带的 http 和 sqlite，不需要 `npm install`。
需要 Node 22.5 或更高版本（本机已装 v24）。

### 2. 后端提供了什么

| 接口 | 说明 |
| --- | --- |
| `GET /api/health` | 健康检查，前端靠它判断后端在不在 |
| `GET /api/content` | 读取全站内容（页面直接编辑的结果，**所有访客共用**） |
| `PUT /api/content` | 保存全站内容，需要发布密码 |
| `POST /api/auth/code` | 发送登录验证码（演示环境直接返回，接短信服务后改掉） |
| `POST /api/auth/login` | 手机号 + 验证码登录 / 自动注册，返回令牌 |
| `POST /api/orders` | 下单并自动报名 |
| `GET /api/enrollments` | 我的课程 |
| `GET/POST /api/progress` | 学习进度 |
| `GET/POST /api/notes` | 课堂笔记 |
| `GET/POST /api/comments` | 课程评价 |
| `GET /api/stats` | 学员数 / 订单数 / 收入 / 完成课时等统计 |

数据全部存在 `server/data/jinghua.db`（SQLite 单文件），备份直接拷这个文件即可。

### 3. 怎么让「别人改完网站就更新」

1. 打开网站，点右下角「✏️ 修改内容」
2. 面板顶部会显示 **已连接后端**
3. 点「发布设置」，填入**发布密码**（默认 `jinghua2026`，正式使用请改掉）
4. 点「开始编辑文字」改内容 → 退出编辑 → 点 **「保存并发布到网站」**
5. 内容写进服务器数据库，**任何人刷新页面都能看到**

> 发布密码在服务器上通过环境变量 `JH_ADMIN_KEY` 修改：
> `set JH_ADMIN_KEY=你的密码` 后再启动服务。

### 4. 部署到公网（让别人不用开你的电脑也能访问）

> 📄 完整的图文步骤在 **[DEPLOY.md](DEPLOY.md)**，最省事的方式是点这个链接一键部署：
> **https://render.com/deploy?repo=https://github.com/uketsutei/jinghua-edu**
> （用 GitHub 账号授权即可，不用另外注册）

GitHub Pages 只能放静态页面，**跑不了后端**。要让后端上线，选任意一个支持 Node 的平台，
把整个项目文件夹传上去即可（已带好 `package.json`，平台会自动识别）：

| 平台 | 免费额度 | 说明 |
| --- | --- | --- |
| Render | 有免费实例 | 新建 Web Service，Build 留空，Start Command 填 `node server/server.js` |
| Railway | 有试用额度 | 直接连 GitHub 仓库即可 |
| Fly.io | 有免费额度 | 需要安装 flyctl |
| 腾讯云 / 阿里云轻量服务器 | 付费（约 ¥60/年） | 国内访问最快，装个 Node 就行 |

部署后在环境变量里设置 `JH_ADMIN_KEY`（发布密码）和 `PORT`（平台通常会自动给）。

**然后把静态网站接到后端上**：打开线上网站的「修改内容 → 发布设置」，
在「后端地址」里填你部署好的地址（例如 `https://jinghua-edu.onrender.com`），保存即可。
这样 GitHub Pages 放页面、独立后端存数据，两边配合工作。

线上版托管在 GitHub Pages 上，上线和更新方式：

1. 在本地改好文件（或从网页「导出修改」拿到新的 `content-overrides.js`）
2. 打开 `菁华教育网课平台` 文件夹，右键 → Git Bash Here / 或在命令行执行：

   ```
   git add -A
   git commit -m "更新内容"
   git push
   ```

3. 等 1 分钟左右，刷新网址即可看到新内容

> 注意：网页上的「修改内容」功能，改动只保存在**你自己的浏览器**里。
> 想让所有访客都看到，需要点「导出修改」，把下载的 `content-overrides.js`
> 替换到 `assets` 文件夹后再 `git push`。

## 怎么打开

双击 `index.html` 即可。建议用 Chrome 或 Edge 浏览器打开。

如果想在手机上看，可以在电脑上把整个文件夹拷到手机上，用浏览器打开 `index.html`；
或者用任何静态服务器（例如 VS Code 的 Live Server）打开。

## 怎么在页面上直接改内容（不用碰代码）

1. 打开网页，点右下角黑色的 **「✏️ 修改内容」** 按钮
2. 点面板里的 **「开始编辑文字」**
3. 页面上所有文字都会出现绿色虚线框，**点一下就能直接改**，改完按回车或点空白处
4. 改完点右下角的 **「编辑中 · 点此完成」** 退出编辑

改动会立刻保存在这台电脑的浏览器里，刷新、关掉重开都还在。

几个说明：

- **同一门课改一次，别处一起变**。比如在课程详情页改了课程名字，首页卡片、课程中心、
  我的学习、老师页里的同一个课程名会同时更新；老师姓名同理。
- **每页独有的文字各自独立**。首页大标题、页脚联系方式这类文字，改的就是那一页。
- **想撤销**：点「修改内容」→「撤销本页」只还原当前页面；「撤销全部」还原所有修改。
- **想让所有人看到修改**：点「导出修改」，会下载一个 `content-overrides.js`，
  用它替换 `assets` 文件夹里的同名文件即可。换台电脑也可以点「导入修改」把文件导回来。
- 想彻底恢复出厂内容：用记事本打开 `assets/content-overrides.js`，把大括号里写成 `{}`。

## 页面结构

| 文件 | 页面 | 说明 |
| --- | --- | --- |
| `index.html` | 首页 | 品牌介绍、教学特色、课程分类、热门课程、直播预告、名师、学员评价 |
| `courses.html` | 课程中心 | 按学段 / 学科 / 难度 / 价格筛选，支持搜索与排序 |
| `course.html` | 课程详情 | 演示播放器、课程亮点、章节目录、课堂笔记、学员评价、相关课程 |
| `learning.html` | 我的学习 | 学习进度、课时完成度、继续学习、课程推荐 |
| `teachers.html` | 名师团队 | 六位主讲老师的简介与所授课程 |
| `login.html` | 登录 / 注册 | 手机号表单校验，含「体验账号」一键进入 |

## 可以体验的功能

- **筛选与搜索**：课程中心左侧筛选条、顶部搜索框（回车即搜）
- **购物车**：任意课程点「加入购物车」，右上角购物车图标可查看、移除、结算
- **结算流程**：结算 → 未登录会跳到登录页 → 登录后自动完成报名 → 课程进入「我的学习」
- **学习进度**：学习中心显示已完成课时与百分比；课程详情页点「标记为已完成」会实时更新
- **演示播放器**：点击课时开始播放，进度条随讲解推进，播完自动标记完成；支持倍速、上一节 / 下一节
- **课堂笔记**：按课时保存，保存在浏览器本地，刷新不丢失
- **数据持久化**：所有状态保存在浏览器 localStorage，换浏览器或清理缓存会重置
- **页面直接编辑**：右下角「修改内容」按钮，点文字就改，支持撤销与导出

## 怎么改成自己的内容

所有课程、老师、评价数据都集中在 `assets/data.js` 一个文件里，用记事本或
VS Code 打开就能改：

- `courses` —— 课程列表（标题、价格、简介、章节、亮点）
- `teachers` —— 老师信息
- `lives` —— 直播安排
- `siteReviews` / `stats` —— 首页评价与数据

配色与字体在 `assets/styles.css` 顶部的 `:root` 里，改 `--brand`（主色）、
`--gold`（强调色）即可整体换色。
